# Поиск и замена в открытом файле

В Code Editor Ctrl+F открывает поиск, Ctrl+H — замену во встроенной
панели Monaco для активного файла. Отдельных кнопок в панели нет. Сочетания работают при активной странице
редактора; если Monaco уже обработал сочетание, повторного вызова не происходит.
Поддерживаются клавиши F/H при русской раскладке через физический код клавиши.

Панель Monaco поддерживает переход между совпадениями, учёт регистра, целые слова,
регулярные выражения и замену одного или всех совпадений. Замена изменяет буфер
редактора, включает признак несохранённых изменений и доступна для отмены Ctrl+Z.
На диск текст попадёт только после сохранения. Поиск работает и с несохранённым
текстом активной вкладки; поиск по всему проекту по-прежнему читает файлы с диска.

Без активного файла и при блокировке редактора сочетания не запускают действия. Esc закрывает
панель Monaco. Проверка: открыть main/main.c, найти printf, проверить учёт регистра,
заменить текст приветствия, проверить признак изменения, отменить Ctrl+Z и сохранить.
