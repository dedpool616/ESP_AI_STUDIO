# Ошибки и предупреждения сборки

На Dashboard перед журналом показываются сообщения компилятора GCC вида
`файл:строка:столбец: error/warning: текст`. Учитываются Windows-пути,
отсутствующий столбец (принимается 1), fatal error и цветовые ANSI-последовательности.
Повторяющиеся сообщения удаляются. Список ограничен 500 сообщениями из последних
256 КБ текущего журнала; сообщения CMake/linker без такого формата остаются в журнале.

После завершения операции нажмите путь файла внутри проекта: откроется Code Editor
и курсор перейдёт к строке/столбцу. Уже открытые несохранённые файлы не перечитываются
с диска. Если код после сборки изменился, указанная строка может отличаться от
места ошибки. Отсутствующий файл даёт сообщение об ошибке внутри приложения.
Пути вне проекта (например SDK) показываются без возможности перехода.

Для проверки без платы: временно уберите точку с запятой в main/main.c, сохраните,
соберите, нажмите ссылку в списке ошибок. Проверьте открытие файла и положение
курсора. Верните код и повторите сборку: список относится уже к новой сборке.
