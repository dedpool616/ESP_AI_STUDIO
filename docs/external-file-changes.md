# Внешние изменения файлов

При активном Code Editor открытые файлы сверяются с диском примерно каждые
2,5 секунды, последовательно. Во время сохранения, модальных операций и блокировки
редактора проверка приостанавливается. При возврате в редактор проверка возобновляется.
Сравнивается содержимое с сохранённой версией вкладки, а не только время файла.

Изменённые или удалённые файлы показываются отдельным уведомлением. Текст вкладки
автоматически не заменяется. «Загрузить с диска» запрашивает подтверждение замены
текста, затем перечитывает актуальный файл. «Сохранить мою версию» подтверждает
перезапись, «Восстановить файл» — создание удалённого файла. Недоступный или ставший
бинарным файл нельзя перезаписать обходом уведомления.

Ctrl+S и «Сохранить всё» передают backend сохранённую исходную версию. Backend
перечитывает файл и отклоняет запись при несовпадении, возвращая конфликт.
Сохранение остальных файлов продолжается. Подтверждённая перезапись проверяет
последнюю показанную внешнюю версию ещё раз, восстановление использует флаг wx,
который не перезаписывает файл, появившийся после подтверждения. Проверка не
обеспечивает межпроцессную блокировку от одновременной записи другим редактором.
Старые окна без новой сигнатуры сохранения получают подсказку о полном перезапуске.

Проверка: открыть тестовый файл, изменить его в другом редакторе и сохранить;
вернуться в Code Editor, проверить уведомление и выбор действий. Повторить с
несохранённым текстом во вкладке; проверить, что Ctrl+S не затёр внешние правки.
На отдельном тестовом файле проверить внешнее удаление и восстановление по подтверждению.
