# COM-порты и прошивка

На Dashboard под сборкой есть блок «Прошивка платы». Кнопка «Обновить порты»
получает порты через pyserial из Python выбранного ESP-IDF. Она не открывает
порт и не сбрасывает устройство. Выбор порта выполняется вручную, по имени и
описанию USB-устройства; автоматически определять плату по описанию нельзя.

Перед прошивкой сохраните файлы и успешно соберите проект. Выберите COM-порт,
нажмите «Прошить» и проверьте подтверждение с портом и target. Запись начинается
только по кнопке «Подтвердить прошивку» и заменяет программу на устройстве.

Backend повторно проверяет выбранный порт, target и путь имеющейся сборки,
запускает idf.py -p COMx -b 460800 flash без shell. ESP-IDF при необходимости
обновляет сборку. Вывод идёт в общий журнал. Сборка и прошивка взаимно исключаются;
редактор проекта и закрытие приложения блокируются до завершения операции.
Установка зависимостей, erase-flash и Serial Monitor не выполняются.

Ручная проверка без записи: подключите плату кабелем с передачей данных,
обновите порты, выберите устройство, откройте подтверждение и нажмите «Отмена».
Если список пуст, проверьте USB-кабель, разъём платы и драйвер устройства.
После отдельного согласия на запись можно проверить успешную прошивку,
недоступный/занятый порт и диагностические сообщения в журнале.
