# Пробная сборка ESP32-S3

Проверка запускается отдельно от интерфейса IDE:

```powershell
node tools/esp-idf-smoke-build.cjs C:\Espressif\tools\eim_idf.json
```

Скрипт читает выбранную установку EIM и локальные export_paths/export_vars из
tools/tools.json. Использует рекомендуемые установленные инструменты для ESP32-S3
и общие инструменты с target `all`. Создаёт копию окружения дочернего процесса;
системные настройки не изменяются. Отсутствующие компоненты не устанавливаются.

В новой уникальной папке `C:\esp_projects\s3-*` создаётся минимальный проект
с app_main, печатающим приветствие. Запускается Python выбранного SDK:
`idf.py -C <папка> -D IDF_TARGET=esp32s3 build`.
Component Manager и ccache отключены. Внешние компоненты не запрашиваются.
Окно процесса скрыто, shell не используется, таймаут — 10 минут.

Журнал: `build.log` в папке тестового проекта. При успехе дополнительно проверяется
наличие `.bin`, `.elf`, загрузчика и таблицы разделов. Эта проверка подтверждает
минимальную сборку ESP32-S3; остальные платы и реальные проекты требуют отдельных
сборок. Прошивка платы не выполняется, пользовательские проекты не изменяются.

Корневую папку можно передать третьим аргументом команды. Запись за пределами
рабочего пространства требует разрешения Codex. Нового элемента интерфейса
эта проверка не добавляет. Подключение сборки пользовательского проекта к IDE —
следующий этап.
