# Настройки проекта

При открытом проекте в меню появляется «Настройки проекта». Можно изменить
плату и закрепить отдельную установленную ESP-IDF за проектом либо использовать
выбор из ESP-IDF Manager. Зависимости и SDK не скачиваются. Выбор сохраняется
в .espai/project.json с сохранением остальных полей; сборка читает idfPath
проекта перед глобальным выбором. Serial Monitor использует глобальный SDK.

Перед сохранением завершите сборку/прошивку и сохраните открытые файлы.
При конфликте платы с sdkconfig или платы/SDK с существующей сборкой сохранение
отклоняется без согласия на резервное копирование. Флажок «Подготовить новую
сборку» перемещает sdkconfig, sdkconfig.old и build в .espai/backups/settings-*.
Исходники остаются на месте. Следующая сборка создаёт новую конфигурацию;
пользовательские настройки старого sdkconfig автоматически не переносятся.
Резервная копия остаётся доступна для ручного восстановления.

При ошибке до сохранения метаданных перемещённые файлы возвращаются обратно.
Если возврат не удался, сообщение содержит пути резервных файлов. Новый JSON
записывается во временный файл и переименовывается. Служебные ссылки отклоняются.

Проверка без платы: открыть настройки тестового проекта, сохранить прежнюю плату
без резервирования, перезапустить и проверить выбор. Затем попробовать другую
плату без флажка (должен быть отказ для настроенного sdkconfig), включить флажок,
сохранить, проверить резервную папку и собрать проект для новой платы.
