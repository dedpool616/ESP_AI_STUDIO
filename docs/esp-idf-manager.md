# ESP-IDF Manager: обнаружение окружения

Первый этап доступен в разделе **ESP-IDF Manager** бокового меню.

Он обнаруживает SDK через `IDF_PATH`, конфигурации Espressif EIM (`eim_idf.json`)
и старого установщика (`idf-env.json`), а также ограниченный поиск в стандартных
каталогах. Полного сканирования дисков нет.

Python выбранной установки имеет приоритет над системным Python. CMake и Ninja
ищутся также в каталогах инструментов Espressif, даже если их нет в PATH.
Показываются фактические пути, версии, источники и ошибки каждого инструмента.

Кнопка **Указать папку ESP-IDF** выбирает корень SDK, а не папку пользовательского
проекта. Выбор сохраняется отдельно от сессий редактора в
`userData/environment-settings.json`. Пункт **Автоматический поиск** сбрасывает
ручной выбор. Некорректная папка или отмена выбора сохраняет предыдущие настройки.

Проверка запускает только известные исполняемые файлы с фиксированным аргументом
`--version`, без shell, с таймаутом 3 секунды и скрытым окном. SDK-скрипты и
activation/export-скрипты не выполняются. Установка компонентов, изменение PATH
и запуск сборки на этом этапе отсутствуют.

Наличие компонентов ещё не подтверждает готовность к сборке: следующие этапы —
проверка совместимости версий, Python-пакетов, toolchain выбранного ESP32 target
и изолированная подготовка окружения процесса сборки.

## Проверки

```powershell
node --test tests/*.test.cjs
npm.cmd run typecheck
node node_modules/eslint/bin/eslint.js .
npm.cmd run build
```

В настоящем приложении:

1. Открыть ESP-IDF Manager и дождаться отчёта. Проверить SDK, Python, Git, CMake,
   Ninja и фактические пути.
2. Нажать «Проверить окружение» повторно: страница остаётся отзывчивой.
3. Выбрать SDK из списка, перезапустить приложение и проверить сохранённый выбор.
4. В выборе папки нажать отмену: предыдущий отчёт и выбор сохраняются.
5. Указать обычную папку проекта: появляется ошибка внутри страницы, старый выбор
   сохраняется. Затем указать папку SDK и убедиться, что выбор работает.
6. Переключить режим на автоматический поиск.
7. Перейти в Code Editor и обратно: редактор сохраняет свои вкладки и правки.
