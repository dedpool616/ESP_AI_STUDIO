# Управление файлами проекта

В Code Editor правый клик по пустому месту дерева открывает контекстное меню
«Новый файл» / «Новая папка» для корня проекта. Правый клик по папке позволяет
создавать внутри неё файл или папку, переименовать её или переместить в корзину.
Правый клик по файлу открывает переименование и удаление. Имя вводится прямо
в дереве: Enter применяет действие, Escape отменяет. Ошибки отображаются под
полем ввода. Отдельное окно используется только для подтверждения удаления.

Удаление требует подтверждения и использует корзину Windows. Если удаляемый
файл или файл внутри удаляемой папки имеет несохранённые изменения, операция
отклоняется до сохранения или закрытия соответствующих вкладок. При переименовании
обновляются пути вкладок и активного файла, несохранённые тексты сохраняются.
Дерево перечитывается после успешной операции. Открывать новый файл нужно из дерева.

Запрещены операции с корнем, .git, .espai, node_modules, build, out и символическими
ссылками. Проверяются имена Windows, относительные пути и существование назначения.
Совпадающее имя отклоняется, в том числе переименование только регистра букв.
Во время сборки или прошивки файловые операции недоступны.

Ручная проверка: создать папку и файл, открыть его и изменить текст, переименовать
файл и папку, проверить содержимое вкладки и сохранить. Проверить отказ удаления
несохранённого файла. Затем сохранить и подтвердить удаление, проверить корзину,
дерево и закрытие вкладки. Проверить совпадающее/недопустимое имя и отмену диалога.
