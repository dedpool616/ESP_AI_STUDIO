# Сравнение версий открытого файла

В уведомлении о внешнем изменении или удалении нажмите «Сравнить». Перед открытием
версия на диске перечитывается. Слева показан диск, справа — текст вкладки,
включая несохранённые правки. Удалённому файлу соответствует пустая левая сторона
с явной пометкой. Если файл стал недоступен, показывается ошибка без изменения буфера.

Используется Monaco DiffEditor, подсвечивающий отличающиеся строки. Обе стороны
только для чтения; сравнение не сохраняет, не восстанавливает и не заменяет файл.
Модели сравнения отделены от моделей вкладок и освобождаются при закрытии.
Окно содержит снимок на момент открытия; для обновления закройте его и откройте
повторно. Закрытие — кнопкой или Esc. Затем можно выбрать действие исходного
уведомления; перезапись по-прежнему требует отдельного подтверждения и проверки.

Проверка: открыть тестовый файл, изменить текст во вкладке без сохранения,
сохранить другую версию во внешнем редакторе, дождаться уведомления и сравнить.
Проверить стороны, подсветку, закрытие по Esc и сохранность правок. Отдельно
проверить удалённый тестовый файл: левая сторона пустая, правая содержит буфер.
