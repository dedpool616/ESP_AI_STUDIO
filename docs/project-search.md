# Поиск по файлам проекта

При открытом проекте выберите «Поиск по проекту», введите текст и нажмите Enter
или «Найти». Поиск буквальный, без регулярных выражений; есть переключатель
«Учитывать регистр». Каждое совпадение показывает файл, строку, столбец и фрагмент
текста. Нажатие открывает соответствующий файл и строку в Code Editor через тот
же механизм, что используется списком ошибок сборки. Уже открытые несохранённые
буферы не заменяются. Положение совпадения относится к сохранённому файлу.

Ищутся только сохранённые UTF-8 файлы до 2 МиБ. Пропускаются бинарные файлы,
невалидный UTF-8, символические ссылки и каталоги .git, .espai, node_modules,
build, out, dist, .idea, .vscode. При обходе проверяется принадлежность пути проекту.
Поиск не записывает файлы и не запускает shell/внешние программы.

Ограничения: до 500 совпадений, 5000 прочитанных текстовых файлов, 10000 элементов
обхода, 32 МиБ прочитанных данных, глубина 32, проверка времени обхода 10 секунд.
При достижении лимита результат помечается частичным. Непрочитанные элементы
учитываются как пропущенные; служебные каталоги исключаются целиком.
Поиск выполняется по кнопке и не запускает параллельные запросы.

Запрос и результаты сохраняются при переходах между страницами. При смене
проекта создаётся отдельный новый экран поиска, старый ответ не обновляет его.
На время сборки/прошивки переход по результату недоступен, сам поиск разрешён.

Проверка без платы: найти `printf` в тестовом проекте, перейти к совпадению и
вернуться к результатам. Проверить Hello/hello с учётом регистра и без него,
текст без совпадений, русские буквы и отсутствие результатов из build.
