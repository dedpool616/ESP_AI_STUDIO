# Проверка сессий редактора

Автоматическая проверка без запуска Electron:

```powershell
node --test tests/editor-session.test.cjs
npm.cmd run typecheck
npm.cmd run build
```

Тесты используют текущие обработчики и эффекты CodeEditorPage с подменёнными
React hooks/IPC, а также основной процесс с подменённым Electron. Они не заменяют
проверку настоящего окна Electron и Monaco.

## Ручная проверка в приложении

1. Открыть проект A, открыть несколько файлов, изменить один без Ctrl+S.
2. Перейти Home → Code Editor: вкладки и текст должны остаться.
3. Открыть проект B. Отменить переключение: проект A и его правки остаются.
4. Повторить и подтвердить переключение с сохранением правок в сессии.
5. Открыть в B файл с тем же относительным путём и изменить его.
6. Вернуться в A: проверить вкладки, активный файл и текст. Вернуться в B:
   убедиться, что его текст независим.
7. Нажать закрытие окна или Alt+F4, затем «Отмена»: окно должно остаться.
8. Повторить и выбрать «Сохранить сессии и выйти». Запустить снова: Home должен
   быть стартовой страницей, а сессии обоих проектов должны восстановиться.
9. Проверить исходники на диске: выход и переключение не записывают буферы в них.
   Для записи исходника по-прежнему нужен Ctrl+S.
10. Закрыть отдельную изменённую вкладку: существующее подтверждение отмены или
    закрытия без сохранения должно работать.
11. Нажать Close Project для проекта с правками. Проверить отмену, затем закрытие
    с сохранением сессии. Home должен остаться доступен, Dashboard исчезнуть.
    Повторно открыть проект из Recent Projects и проверить правки.
12. Для тестового проекта закрыть IDE и переместить его папку через Проводник.
    После запуска должно появиться сообщение о недоступном проекте.
    Отменить диалог: приложение должно остаться рабочим, запись — в Recent Projects.
13. Выбрать недоступную запись и указать новую папку того же проекта. Проверить
    обновлённый путь, вкладки и несохранённый текст, затем повторный запуск IDE.
14. Указать папку без ESP-IDF проекта: диалог должен показать ошибку и позволить
    повторить выбор, сохранив старую запись и буферы.
15. Выбрать «Убрать из списка» для недоступной записи. Она должна исчезнуть из
    Recent Projects. Файлы и сохранённая сессия не удаляются.
16. Нажать правой кнопкой мыши на любой доступный Recent Project → «Убрать проект».
    Запись исчезает, но открытый проект остаётся открыт, файлы и сессия сохраняются.
    Проверить закрытие меню кликом снаружи и Escape.
17. Изменить несколько открытых файлов одного проекта и нажать «Сохранить всё»
    в верхней панели Code Editor. Проверить текст на диске и индикаторы изменений.
    Несохранённые файлы другого проекта должны остаться без изменений.

## Границы текущего этапа

- Сохранение сессий выполняется через 300 мс после последнего изменения и
  дополнительно перед подтверждённым штатным выходом. При аварийном завершении
  последние изменения после последней записи могут не восстановиться.
- Буферы восстанавливаются из снимка сессии. Синхронизация с внешним редактором
  и обнаружение изменений файлов на диске пока не реализованы.
- Close Project и обработка недоступных Recent Projects реализованы. Перед merge
  требуется ручная проверка настоящего Electron-окна по сценариям выше.
- При переносе пути в папку с уже существующей непустой сессией операция
  отменяется, чтобы не перезаписывать вкладки и буферы другой сессии.
- Зависимости, AI, ESP-IDF Build/Flash и массовое форматирование не менялись.
