# Serial Monitor

Раздел Monitor читает сообщения платы через pyserial из Python выбранного SDK.
Новые зависимости не устанавливаются. Откройте проект с выбранной платой,
обновите COM-порты, выберите устройство и скорость (по умолчанию 115200),
нажмите «Подключить». Скорость должна совпадать с настройкой вывода прошивки.

Вывод декодируется как UTF-8, последние 256 КБ хранятся в памяти main process.
«Очистить вывод» очищает только журнал. Переход между страницами или проектами
не отключает устройство: фактические порт и скорость видны в статусе.
«Отключить» завершает отдельный Python-процесс и освобождает порт; при закрытии
приложения процесс также завершается. Перед прошивкой отключите монитор;
backend не разрешает прошивку, пока монитор подключается или держит порт.

Монитор работает только на чтение, команды на плату не отправляются. RTS/DTR
устанавливаются в false перед открытием, но поведение USB-драйвера и сброс
конкретной платы требуют проверки на устройстве.

Без платы проверяются валидация, потоковый вывод, очистка, отключение, блокировка
прошивки и обработка ошибок на заглушках. С реальной ESP32-S3 ещё нужно проверить:
подключение на 115200, получение приветствия, смену страниц, отключение USB,
занятый порт, повторное подключение и освобождение порта перед прошивкой.
Serial Monitor не проверяет автоматически, какая программа работает на плате.
