# Быстрое открытие файла

При открытом проекте нажмите Ctrl+P или «Открыть файл… Ctrl+P» в верхней панели.
Введите часть имени или относительного пути. Поиск без учёта регистра,
обратные слеши пути принимаются как прямые. Точное имя файла имеет приоритет,
затем начало имени, часть имени и совпадение в пути. Показываются первые 100 файлов.
Стрелки вверх/вниз выбирают результат, Enter открывает, Esc или клик вне окна
закрывают его. Tab остаётся внутри окна. На русской раскладке учитывается KeyP.

Список перечитывается при каждом открытии окна. Backend читает имена, не содержимое.
Пропускаются служебные каталоги, ссылки и файлы больше 2 МиБ. Неизвестный бинарный
файл может оказаться в списке, но редактор отклонит его при открытии. Лимиты обхода:
10000 файлов, 20000 элементов, глубина 32 и 5 секунд между проверками элементов.
Если обход ограничен или папка недоступна, показывается сообщение о частичном списке.

Открытие использует существующие вкладки и не заменяет несохранённое содержимое.
При сборке, сохранении и других модальных операциях быстрый переход блокируется.
После изменения preload требуется полный перезапуск приложения; старое окно
показывает понятную подсказку, если API списка ещё не подключён.

Проверка: Ctrl+P, `main.c`, Enter; проверить поиск `main/`, выбор стрелками, Esc,
открытие уже изменённой вкладки без потери текста и обновление списка после создания файла.
